# DietSense — 台灣在地化 AI 飲食營養分析代理人

> **Conversational Domain AI Agent** · Natural Language Understanding · Active Clarification · RAG · Deterministic Nutrition Calculation

DietSense 是一項研究提案，目標是讓使用者以繁體中文自然語句記錄日常飲食，例如「中午吃一碗牛肉麵，湯喝一半」。系統規劃辨識食材、份量與攝食比例，針對資訊不足之處主動澄清，再使用有來源標記的營養資料及確定性運算引擎估算營養攝取。

## 02｜研究核心

- **自然語言飲食理解：** 辨識「一碗」「半碗」「去糖」「湯喝一半」等在地飲食描述。
- **主動澄清：** 針對份量、湯汁、配料與料理歧義提出必要追問。
- **檢索增強生成（RAG）：** 從台灣食品營養成分資料庫及 USDA FoodData Central 等資料來源檢索相關資訊。
- **確定性營養運算：** 將語言模型的語意理解與數值計算分離，保留來源與計算依據。
